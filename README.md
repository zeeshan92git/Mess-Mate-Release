# MessMate

**Track meals. Verify bills.**

MessMate helps University of the Punjab hostel residents keep a personal lunch
and dinner record and compare their calculated monthly total with the hostel bill.

MessMate is an **independent student utility**. It is not an official University
of the Punjab application, university administration service or hostel management
system. This repository distributes Android downloads and public documentation;
application source code is maintained privately.

## Download

[Download the latest Android release](https://github.com/zeeshan92git/Mess-Mate-Release/releases/latest)

Open the release's **Assets** section and choose its `MessMate-…-universal.apk`
file. If no release is listed yet, the public APK has not been published. Do not
download an APK from an unrelated repository, message or unofficial mirror.
Android compatibility and known limitations are listed with each tested release.

## What MessMate does

- Personal lunch/dinner attendance with corrections and actual meal prices.
- A reusable weekly mess menu with historical versions.
- Calendar, monthly history, running totals and official-bill comparison.
- PDF reports and manually saved backups.
- Local lunch/dinner reminders, subject to Android permissions and delivery limits.
- Light/dark appearance and offline-first records.
- Compatible in-app updates, with a download notice when a new Android app is needed.

## Install on Android

1. Read the release's Android requirements and known limitations.
2. Download its universal APK, then open it using Android's Downloads/Files app.
3. If Android asks, allow this browser/file manager to install that APK. No broad
   storage permission or automatic installer is required by MessMate.
4. Confirm installation. If Android says it is incompatible or invalid, stop and
   report the message; do not uninstall an existing MessMate installation to fix it.
5. Open MessMate and complete student/hostel setup. No account is required.

Android may show a warning for apps distributed outside an app store. Review the
source and release first. Do not bypass a security block or install an unverified file.

## Updating without losing records

**Install the new APK over the existing app. Never uninstall or clear app data
to update.** Official replacement APKs keep package `com.messmate.app`, the same
signing identity and a higher Android versionCode. Keep a backup before changing
phones or testing upgrades. Compatible small updates may download automatically;
restart from idle Home when MessMate offers it, after finishing edits/saves.

## Offline and privacy

Your profile, menus, answers, prices and bills stay on your device. There is no
account, cloud sync or automatic cloud backup. Save a backup to a durable folder
yourself. Uninstalling or losing a device can remove records.

Minimal feature-use counts may be enabled in the beta, without your name, hostel,
room, meal answers, dishes, prices, bills or backup contents. There are no ads or
screen recordings. Existing refusals are respected. Privacy Notice in the app
contains a sharing control; all core functions remain available without sharing.
Read [Privacy](PRIVACY.md) for service/retention/contact details and release gates.
