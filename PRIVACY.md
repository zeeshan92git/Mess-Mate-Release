# MessMate Privacy Notice

MessMate is an independent student utility, not an official university service.

## Local records

Your student profile, hostel/room, menus, meal answers, prices and bills stay in
local storage. No account or cloud backup is provided. Save/Share actions can
create files containing personal records; protect the destination and recipients.
Uninstalling, clearing storage or losing a device can remove your local records.

## Basic feature counts

The beta can send only app opens, attendance-feature use, menu saves, monthly-review
views, successful backup exports and verified update-link opens. These counts do
not include student identities, hostel/room, meal answers, dish names, meal dates,
prices, bill amounts, documents, images, location or student identifiers.

The processing service is PostHog. Requests use a temporary random identifier
held only in memory; it is not connected to your profile and is not a persistent
installation identifier. Counts are approximate, not a reliable count of students.
There is no advertising, cross-app tracking, screen recording, replay, automatic
screen tracking or enriched device data. The service necessarily sees connection
information such as an IP address; the publisher must disable project IP capture
and location enrichment and review processor configuration.

Fresh installations may use automatic feature counts when collection is configured.
Previous refusals remain off. You can withdraw using **Privacy Notice → Share
basic feature counts** in the app without affecting core features. Browser privacy
signals are respected. Where prior consent is required, collection must stay off
until a choice is given on that screen. Publisher configuration does not override
an earlier refusal. Storage failures keep sharing off.

Withdrawal stops new requests and discards pending events; it cannot recall data
already received. The sharing choice stays on the device/browser, outside backups.

## Updates

Update checks contact Expo and GitHub without your mess records. Download pages
open in your browser. Those services receive ordinary connection information.
Offline failures never remove local records.
